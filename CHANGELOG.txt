ARIA SONG SERVER - VERSION HISTORY
==================================

Version 1.7.0
Created: 2026-08-30

Changed:
- Advanced the shared Aria release from 1.6.0 to 1.7.0 for the new Mac Player and sidebar experience.


Version 1.6.0
Created: 2026-08-30

Changed:
- Advanced the shared Aria release from 1.5.0 to 1.6.0 for the iPhone, iPad, and Mac interface rework.


Version 1.5.0
Created: 2026-08-29

Added:
- Added persistent GET, PUT, and DELETE playlist APIs shared by every Aria client.
- Added atomic storage for playlist names, ordered track IDs, custom covers, and revisions.
- Added validation, cover-size limits, duplicate track removal, and stale-revision protection.

Version 1.2.2
Created: 2026-08-29

Changed:
- Advanced the shared Aria release from 1.2.1 to 1.2.2 for the Mac karaoke lyrics refinement.


Version 1.2.1
Created: 2026-08-28

Changed:
- Advanced the shared Aria release from 1.2.0 to 1.2.1 for the iPhone/iPad playlist persistence fix.


Version 1.2.0
Created: 2026-08-28

Added:
- Added `GET /api/tracks/{id}/lyrics` for synchronized and plain lyrics.
- Added local `.lrc`, `.lyrics`, `.txt`, and embedded-tag lyric discovery.
- Added no-key LRCLIB lookup with responsible identification and persistent caching.
- Added one-day negative-result caching to avoid repeated unavailable lookups.

Changed:
- Advanced the shared Aria release from 1.1.4 to 1.2.0 for the lyrics feature.


Version 1.1.4
Created: 2026-08-19

Added:
- Added this permanent per-version history with creation dates and release notes.

Changed:
- Advanced the shared Aria release from 1.1.3 to 1.1.4.
- Updated the repository rules so every future push records its version here.


Version 1.1.3
Created: 2026-08-19

Added:
- Added catalog, search, artwork, streaming, metadata, and download APIs for Aria.
- Added server-side YouTube Music album downloads and progress reporting.
- Added a Wi-Fi and Tailscale network watchdog for automatic recovery.
- Added a validated nightly yt-dlp updater with rollback and automatic repair retry.
- Added the Aria version to the API response and HTTP server header.

Fixed:
- Repaired YouTube HTTP 403 failures caused by player and challenge changes.
- Made already-downloaded albums finish successfully instead of returning status 1.

Note: This was the first release recorded after version history was introduced.
