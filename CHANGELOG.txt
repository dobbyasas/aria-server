Version 1.13.2
Created: 2026-09-01

Fixed:
- Included canonical album IDs in every track response so clients can delete albums directly and reliably.
- Refreshed the catalog once before rejecting legacy track-based album deletion for a missing track.

Version 1.13.1
Created: 2026-09-01

Fixed:
- Removed obsolete `YouTube Music / Playlist` copies when a proper matching album track is already reused.
- Cleaned deleted legacy track IDs from shared playlists while preserving the real song copy.

Version 1.13.0
Created: 2026-09-01

Added:
- Added per-song YouTube metadata and artwork processing for individual-song and playlist downloads.

Changed:
- Playlist tracks keep their own title, artist, album, year, track number, genre, and cover instead of playlist-level placeholder metadata.
- Reused standalone tracks are refreshed in place without downloading duplicate audio.
- Legacy tracks tagged as album "Playlist" by artist "YouTube Music" are repaired and moved out of the album collection.

Version 1.12.1
Created: 2026-08-30

Fixed:
- Reused uniquely titled existing songs even when an older playlist download had overwritten their original artist metadata.

Version 1.12.0
Created: 2026-08-30

Added:
- Added YouTube song and playlist inspection before downloading.
- Added deterministic shared Aria playlist creation from YouTube playlists.
- Added download status fields for reused songs and created playlist size.

Changed:
- Song matching now checks YouTube video IDs first and normalized title/artist metadata second.
- Playlist downloads request only missing source positions and reuse existing catalog tracks in playlist order.

Version 1.11.0
Created: 2026-08-30

Added:
- Added explicit album, individual-song, and full-playlist download modes.
- Added a persistent standalone-track manifest so song and playlist downloads do not create incomplete albums.
- Added protected album-deletion endpoints with playlist cleanup and sidecar removal.
- Added tests for standalone catalog behavior, album deletion, playlist cleanup, and download-mode validation.

Changed:
- Album summaries now exclude standalone song and playlist downloads while the tracks remain available in the main song library.

Version 1.10.0
Created: 2026-08-30

Added:
- Added a protected endpoint that downloads a validated YouTube Music image and replaces the embedded cover on every track in the selected album.
- Added album-cover refresh tests covering trusted YouTube hosts, album-wide catalog updates, and artwork URL cache busting.

Changed:
- Album and track artwork URLs now include their source file modification token so replaced covers refresh immediately on every device.
- Cover replacement is blocked while a music download is active to prevent concurrent file mutation.
